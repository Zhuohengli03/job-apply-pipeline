# 个人求职档案（profile.md 模板）

两种填法：①把简历发给 AI，说“帮我建求职档案”，它会按 `onboarding.md` 从简历预填、再分几轮问你；②自己照这份模板填。填好后存到自己的求职文件夹（和投递追踪 Excel 放一起），文件名 `profile.md`。

标【必填】的小节没填完不能开始投递；其余可以先写「未知，问我」，投递中遇到再补。不知道的项不要留空让 AI 猜。**这份文件含个人信息，不要随 skill 分享给别人。**
