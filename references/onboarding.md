# 第一次使用：帮用户建 profile.md

目标：用 10 分钟左右、尽量少打字，建出一份能直接用来投递的档案。原则：**能从简历读出来的不问；必须问的分轮问，每轮不超过 5 题，能做成选择题的做成选择题；不知道的写「未知，问我」，绝不猜。**

## 第 1 步：收材料（一句话请求）
请用户一次性给：
- 所有在用的简历 PDF（中英文、不同方向的版本都给，旧版不要）；
- 想投的方向（例：“美国产品岗 + 国内游戏策划”）；
- 已有的投递记录（Excel/表格/截图都行，没有就说没有）。

## 第 2 步：从简历预填（不要问用户）
按 `profile-template.md` 的结构，从简历里抽：姓名、邮箱、电话、地址/城市、链接、教育（学校、学位、专业、起止年月、GPA）、经历、技能、获奖、可量化的数字。每条后面标「（简历）」表示来源。

同时整理两张清单，留到第 4 步让用户确认：
- **经历分类**：简历里每段经历是“雇佣/实习”还是“个人项目/创业/社团/课程项目”。只有前者能填进表单的 Work Experience；后者只进项目栏或 cover letter。（真实事故：个人项目被解析成 “Founder” 工作经历提交出去。）
- **数字口径**：简历里每个数字，问清楚能不能对外引用、怎么说才准确（例：“上线后从 53% 降到 38%”不能说成“使流失下降 15 个百分点”；“刚上线、还没有线上数据”的功能不能写效果）。

## 第 3 步：分轮提问
有选择题工具（如 AskUserQuestion）就用；没有就在消息里编号列出、让用户按编号回复。每轮问完再进下一轮。

**第 1 轮 · 身份与授权（必问，影响每一份申请）**
1. 想投哪些国家/地区？
2. 在目标国家有没有工作授权？（例：美国 F-1 OPT / H-1B / 绿卡 / 公民 / 无）
3. 现在或将来需不需要公司担保签证？
4. 愿意搬迁吗？
5. 有没有 SSN（或当地的税号）？——只问“有/没有”，号码本身永远不记。

**第 2 轮 · 方向与偏好**
1. 目标岗位方向（多选：产品 / AI 产品 / 增长 / 运营 / 数据分析 / 游戏策划 / 游戏运营 / 用户研究 / 其他）
2. 每个方向用哪份简历？（把第 1 步收到的文件名列出来让用户对应）
3. 能接受的经验要求上限（应届 only / ≤2 年 / ≤3 年）
4. 不投的公司或行业（例：自己处理的公司、博彩、纯销售）
5. 每天大概投多少份？期望薪资怎么填（接受标价 / 面议 / 具体数字）？

**第 3 轮 · 表单固定答案**
1. EEO：性别、种族/族裔、退伍军人、残障——每项都可以选“不愿透露”。
2. 犯罪记录、愿意背调：如实回答。
3. 允许代填电子签名（只填姓名+日期）吗？
4. 何时可入职？
5. 如果投国内校招：籍贯、现居地、学历类型（统招全日制/海外）、是否服从调剂、微信号。出生年月只在国内表单必填时用，问一次即可。

**第 4 轮 · 运行设置**
1. 投递表放哪里？（没有就用 `scripts/tracker_update.py init` 新建，问存放位置）
2. 用哪个浏览器/哪个邮箱收招聘邮件？
3. 已经用过名额的限投平台有哪些？（例：某公司校招每人 2 个志愿，已用 1 个）
4. 哪些情况需要通知你？（默认：验证码、同意项、限投候选、面试/笔试）

另外确认第 2 步的两张清单（经历分类、数字口径）——这一步不能省。

## 第 4 步：生成、确认、保存
1. 按模板写出完整 `profile.md`；没答的写「未知，问我」。
2. 给用户看一份**简短摘要**（不是全文）：工作授权与担保答案、哪些经历算工作经历、简历对应关系、EEO、未知项列表。请用户确认或修改。
3. 确认后存到用户的求职文件夹（和投递表放一起）；在 ChatGPT 里则给用户下载，并提醒上传到 Project 文件。
4. 提醒用户：档案里有个人信息，**不要把 profile.md 随 skill 一起分享给别人**。

## 之后：边投边补
- 投递中遇到档案没有的问题（如“是否会说日语”“毕业证编号”），先停下问用户，答完问一句“要不要记进档案，以后同类问题直接用？”同意就写回 profile.md。
- 名额用掉、简历换版、搬家、拿到新授权时，更新对应小节，并在档案顶部改“最后整理”日期。
